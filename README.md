# 動くナンプレ（NumPre Shift）
### 〜スライドパズル×ナンバープレイス〜

15パズルのスライドアクションとナンプレの論理思考を融合した新感覚9×9ロジックパズルWebアプリケーションです。

---

## 🌟 主な特徴・ゲームシステム

1. **自由なマウスドラッグ ＆ 連動一括スライド**
   - 直感的なマウスドラッグ（またはクリック/タッチ）で数字タイルを空きマスへ移動。
   - 複数タイルの連動一括スライド（1列まるごと押し出し）にも対応。
2. **100%解ける論理生成エンジン ＆ 孤立マス防止**
   - バックトラッキングによる完成盤面生成から、各3×3ブロック内でスライド可能な移動経路を保証。
   - 鍵マス（固定数字）に囲まれて動かせなくなるマスが発生しないBFSブロック連結性検証を実装。
3. **視認性に優れたタイルデザイン**
   - **動かせない固定数字**: 重厚な斜体セリフ書体（FIX枠付き）。
   - **動かせる数字**: 直立の白タイル。
4. **オンラインランキング（サーバー保存型）**
   - **集計期間**: 総合（全期間） / 月間（直近30日） / 週間（直近7日）
   - **難易度**: 入門 / 中級 / 上級 / 達人
   - **部門**: 「✨ ヒントなし限定部門」フィルター
   - クリアタイム（早い順）および移動手数（少ない順）で自動集計。
5. **yukiyanArt 公式アプリ連携（自社広告枠）**
   - 画面下部に `yukiyanArt` の各アプリ（Chronos、Desk Chat、AURAGALLERY等）を7秒ごとに自動カルーセル表示。
   - 「Feedback & Release Hub」への直通リンクで、不具合報告やご要望の受付窓口と連携。

---

## 🚀 起動方法

### 方法1: `start.bat` をダブルクリック（最も簡単）
フォルダ内の `start.bat` をダブルクリックするだけで、サーバーが起動し、自動的にブラウザでゲーム画面が開きます。

### 方法2: コマンドラインからの起動
```bash
node server.js
```
起動後、ブラウザで `http://localhost:3000/` にアクセスしてください。
